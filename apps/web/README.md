# PowerChain Relief Web

Next.js 16.3 + React 19 website and operator-facing Solana surfaces.

- `/` product, architecture, Web3 ecosystem and dashboard preview
- `/solana` operations console
- `/programs` program assurance
- `/network` provider/source-of-truth architecture
- `/status` readiness/quorum/SLO
- `/docs` documentation

`@web3icons/react` supplies network, token and wallet SVG React components. Web3 branding is used in ecosystem, wallet, asset and network surfaces; the hero stays architecture-first.

Provider credentials and RPC URLs remain server-side behind same-origin `/api/*` routes.
